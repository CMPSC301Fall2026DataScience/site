# Build Process for CMPSC 301 Website

## ⚠️ CRITICAL: Build Order

**ALWAYS** follow this build order:

### Option 1: Use the Build Script (Recommended)

```bash
./build_jupyterlite.sh
```

This script automatically:
1. Checks for JupyterLite installation
2. Installs WebR kernel if needed
3. Cleans previous build
4. Builds JupyterLite in `docs/live/`

### Option 2: Manual Build

If you need to rebuild everything from scratch:

```bash
# Step 1: Render Quarto site (this generates docs/ folder)
quarto render

# Step 2: Build JupyterLite (this adds JupyterLite to docs/live/)
jupyter lite build --output-dir docs/live

# Step 3: Commit and push
git add docs/ jupyter-lite.json .jupyterlite.doit.db
git commit -m "Update site build"
git push
```

## ⚠️ WARNING: Order Matters!

**DO NOT** run `quarto render` after building JupyterLite locally, as it will **wipe out** the JupyterLite build in `docs/live/`.

### Why?

- `quarto render` generates the entire `docs/` directory
- `docs/live/` initially only contains a README and content notebooks
- When you run `jupyter lite build --output-dir docs/live`, it adds JupyterLite files to `docs/live/`
- If you run `quarto render` again, it regenerates `docs/` and resets `docs/live/` to its original state

## GitHub Actions Workflow

The GitHub Actions workflow (`.github/workflows/deploy.yml`) handles this correctly:

1. ✅ Installs dependencies
2. ✅ Renders Quarto site
3. ✅ Builds JupyterLite
4. ✅ Deploys to GitHub Pages

**You don't need to commit the built JupyterLite files** - GitHub Actions will build them automatically on each push.

## Local Development Workflow

### Just updating Quarto content (Markdown, QMD files):

```bash
quarto render
git add docs/
git commit -m "Update content"
git push
```

GitHub Actions will rebuild JupyterLite automatically.

### Updating JupyterLite configuration:

```bash
# Edit jupyter-lite.json or notebooks in live/content/

# Rebuild JupyterLite
jupyter lite build --output-dir docs/live

# Commit both config and build
git add jupyter-lite.json docs/live/
git commit -m "Update JupyterLite"
git push
```

### Testing locally:

```bash
# Build everything
quarto render
jupyter lite build --output-dir docs/live

# Test the site
cd docs
python3 -m http.server 8000

# Open http://localhost:8000 in your browser
```

## Common Issues

### Issue: JupyterLite doesn't load on GitHub Pages

**Solution**: Check that `baseUrl` in `jupyter-lite.json` is set to `"./"` (relative path).

### Issue: docs/live/ is empty or missing JupyterLite files

**Solution**: Run `jupyter lite build --output-dir docs/live`

### Issue: Quarto wiped out my JupyterLite build

**Solution**: Don't run `quarto render` after building JupyterLite. Always build in the correct order.

### Issue: GitHub Pages shows old content

**Solution**: 
1. Check GitHub Actions completed successfully
2. Wait 2-3 minutes for deployment
3. Hard refresh your browser (Cmd+Shift+R on Mac, Ctrl+Shift+R on Windows)

## Quick Reference
